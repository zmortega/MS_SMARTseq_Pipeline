# SMARTseq HT scRNA-seq Pipeline

Full-length, plate-based single-cell RNA-seq differential expression pipeline.
Optimized for **Takara SMARTseq mRNA HT** kits on **Apple Silicon Mac** with mouse (**GRCm39 / GENCODE vM33**).

---

## Pipeline overview

```
FASTQ (R1/R2 per cell)
    │
    ▼
[1] FastQC          → per-cell read quality reports
    │
    ▼
[2] Trimmomatic     → adapter trimming, quality filtering
    │
    ▼
[3] HISAT2          → splice-aware alignment to GRCm39
    │
    ▼
[4] featureCounts   → gene-level count matrix (all cells → one matrix)
    │
    ▼
[5] DESeq2          → differential gene expression, PCA, volcano, heatmap,
                       expression matrix, pairwise comparisons
```

## Quick start

### 1. Install dependencies

```bash
conda env create -f environment.yml
conda activate smartseq_ht
```

### 2. Build the HISAT2 index (one-time)

```bash
hisat2-build -p 8 reference/GRCm39.primary_assembly.genome.fa reference/hisat2_index/genome
```

### 3. Prepare your metadata

Edit `data/metadata.csv` — one row per cell with columns:
`cell_id`, `strain`, `condition`, `batch`

See `data/metadata_example.csv` for format reference.

### 4. Configure

Edit `config.yaml`:
- Set `FASTQ_DIR` to your folder of `.fastq.gz` files
- Set `METADATA_FILE` to your metadata CSV
- Set `REFERENCE_LEVEL` to your baseline condition (e.g. `CD45pos_MHCIIpos`)

### 5. Run the pipeline

```bash
python pipeline.py --config config.yaml
```

## File naming convention

The pipeline expects paired-end FASTQ files named:
```
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R1_001.fastq.gz
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R2_001.fastq.gz
```

Examples:
- `NOD_A1_S1_L002_R1_001.fastq.gz`
- `B6G7_H12_S96_L001_R1_001.fastq.gz`

Update `R1_SUFFIX` / `R2_SUFFIX` in `config.yaml` if your naming differs.

## NOD strain-specific plots (`scripts/nod_plots.R`)

Generates volcano plots and violin plot series for pairwise comparisons within
the NOD strain only. Produces **6 PDF files** (3 volcano + 3 violin) for the
following contrasts:

| Comparison | Volcano | Violins |
|---|---|---|
| CD45+ MHCIIpos vs CD45− MHCIIhi | ✓ | ✓ |
| CD45+ MHCIIpos vs CD45− MHCIIlo | ✓ | ✓ |
| CD45− MHCIIhi vs CD45− MHCIIlo  | ✓ | ✓ |

Each violin PDF contains **20 panels** (top 10 up-regulated + top 10
down-regulated DEGs by adjusted p-value), displaying VST-normalized expression
with gene symbols as labels.

**Run:**
```bash
cd ~/Desktop/MS_SMARTseq_Pipeline
Rscript scripts/nod_plots.R 2>&1 | tee results/05_dge/NOD_plots/nod_plots.log
```

**To run on a different machine:** update `base_dir` at the top of `scripts/nod_plots.R`.

**Required R packages:** `DESeq2`, `ggplot2`, `ggrepel`, `dplyr`, `tidyr`, `patchwork`

```r
install.packages(c("ggrepel", "patchwork"))
BiocManager::install("DESeq2")
```

## Advanced usage

### Resume a failed run
```bash
python pipeline.py --config config.yaml --resume
```

### Run only specific steps
```bash
python pipeline.py --config config.yaml --steps align,count,dge
```

### Process a subset of cells
```bash
python pipeline.py --config config.yaml --cells NOD_A1_S1_L002,NOD_A2_S2_L002
```

### Run QC summary and flag low-quality cells
```bash
python qc_summary.py --config config.yaml
```
Then update `METADATA_FILE` in `config.yaml` to `results/qc_summary/metadata_qc_pass.csv` and re-run DGE:
```bash
python pipeline.py --config config.yaml --steps dge
```

### Batch correction
In `config.yaml`:
```yaml
DESIGN_FORMULA: "~ batch + condition"
```
Your `metadata.csv` must have a `batch` column. Note: single-strain subsets
(e.g. NOD only) share one batch and should use `~ condition` only.

## Experiment-specific notes

- **Strains:** NOD, B6G7, B6MHCIIGFP, NODPDL1
- **Conditions:** `CD45pos_MHCIIpos` (wells A1–A12), `CD45neg_MHCIIlo` (wells B1–E6),
  `CD45neg_MHCIIhi` (wells E7–H12)
- **Plate quirks:** B6MHCIIGFP wells H1–H12 are empty; NODPDL1 plate layout is
  flipped relative to the other three strains
- **Batches:** B6G7 and B6MHCIIGFP = L001; NOD and NODPDL1 = L002
- **Reference level:** `CD45pos_MHCIIpos` (used as DESeq2 baseline condition)
- **Aligner:** HISAT2 (switched from STAR due to RAM constraints on Apple Silicon)
- **Annotation:** GENCODE vM33 primary assembly GTF
