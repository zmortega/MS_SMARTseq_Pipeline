# SMARTseq HT scRNA-seq Pipeline

Full-length, plate-based single-cell RNA-seq differential expression pipeline.
Optimized for **Takara SMARTseq mRNA HT** kits on **Apple Silicon Mac** with mouse (**GRCm39 / GENCODE vM33**).

---

## Pipeline overview

```
FASTQ (R1/R2 per cell)
    │
    ▼
[1] FastQC          → per-cell read quality reports
    │
    ▼
[2] Trimmomatic     → adapter trimming, quality filtering
    │
    ▼
[3] HISAT2          → splice-aware alignment to GRCm39
    │
    ▼
[4] featureCounts   → gene-level count matrix (all cells → one matrix)
    │
    ▼
[5] per_strain_plots.R  → independent per-plate DESeq2, volcano plots,
                           violin plots, and expression matrices
```

## Quick start

### 1. Install dependencies

```bash
conda env create -f environment.yml
conda activate smartseq_ht
```

### 2. Build the HISAT2 index (one-time)

```bash
hisat2-build -p 8 reference/GRCm39.primary_assembly.genome.fa reference/hisat2_index/genome
```

### 3. Prepare your metadata

Edit `data/metadata.csv` — one row per cell with columns:
`cell_id`, `strain`, `condition`, `batch`

See `data/metadata_example.csv` for format reference.

### 4. Configure

Edit `config.yaml`:
- Set `FASTQ_DIR` to your folder of `.fastq.gz` files
- Set `METADATA_FILE` to your metadata CSV

### 5. Run alignment and counting

```bash
python pipeline.py --config config.yaml
```

### 6. Run per-strain DGE and plots

```bash
cd ~/Desktop/MS_SMARTseq_Pipeline
Rscript scripts/per_strain_plots.R 2>&1 | tee per_strain_plots.log
```

> **Warning:** This script wipes and rebuilds `results/05_dge/` entirely on every run.
> Upstream folders (01–04, qc_summary) are never touched.

## File naming convention

The pipeline expects paired-end FASTQ files named:
```
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R1_001.fastq.gz
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R2_001.fastq.gz
```

Examples:
- `NOD_A1_S1_L002_R1_001.fastq.gz`
- `B6G7_H12_S96_L001_R1_001.fastq.gz`

Update `R1_SUFFIX` / `R2_SUFFIX` in `config.yaml` if your naming differs.

## Per-strain DGE analysis (`scripts/per_strain_plots.R`)

Each plate/strain is treated as a fully independent experiment. DESeq2 is run
separately per strain with no cross-plate pooling.

### Normalization

Size factors are estimated using only the **CD45pos_MHCIIpos (A1–A12) wells**
of each plate as the reference. The geometric mean expression profile is
computed from those 12 cells (genes with any zero counts in the reference
excluded), and median-of-ratios scaling is applied to all cells on that plate.
This ensures every plate is normalized to its own internal reference population
rather than a global cross-plate average.

### Contrasts (per strain)

| Comparison | Volcano | Violins |
|---|---|---|
| CD45+ MHCIIpos vs CD45− MHCIIhi | ✓ | ✓ |
| CD45+ MHCIIpos vs CD45− MHCIIlo | ✓ | ✓ |
| CD45− MHCIIhi vs CD45− MHCIIlo  | ✓ | ✓ |

Each violin PDF contains **20 panels** — top 10 up-regulated + top 10
down-regulated DEGs by adjusted p-value — with gene symbols as labels and
jittered VST-normalized expression points overlaid.

### Expression matrix columns

| Column | Description |
|---|---|
| `ensembl_id` | Ensembl gene ID |
| `gene_symbol` | Common gene name (GENCODE vM33) |
| `mean_VST_CD45pos_MHCIIpos` | Mean VST-normalized expression, CD45+ MHCIIpos cells |
| `mean_VST_CD45neg_MHCIIhi` | Mean VST-normalized expression, CD45− MHCIIhi cells |
| `mean_VST_CD45neg_MHCIIlo` | Mean VST-normalized expression, CD45− MHCIIlo cells |
| `rank_upregulated_MHCIIhi` | Upregulation rank in MHCIIhi vs CD45pos (1 = most upregulated) |
| `rank_upregulated_MHCIIlo` | Upregulation rank in MHCIIlo vs CD45pos (1 = most upregulated) |

Ranks are based on a combined score of `log2FoldChange × -log10(padj)`,
rewarding genes that are both strongly and significantly upregulated. Genes
that are not upregulated (log2FC ≤ 0) or have missing statistics receive `NA`.

### To run on a different machine

Update `base_dir` at the top of `scripts/per_strain_plots.R`, then:

```bash
Rscript scripts/per_strain_plots.R 2>&1 | tee per_strain_plots.log
```

## Advanced usage

### Resume a failed run
```bash
python pipeline.py --config config.yaml --resume
```

### Run only specific steps
```bash
python pipeline.py --config config.yaml --steps align,count,dge
```

### Process a subset of cells
```bash
python pipeline.py --config config.yaml --cells NOD_A1_S1_L002,NOD_A2_S2_L002
```

### Run QC summary and flag low-quality cells
```bash
python qc_summary.py --config config.yaml
```
Then update `METADATA_FILE` in `config.yaml` to `results/qc_summary/metadata_qc_pass.csv` and re-run DGE:
```bash
python pipeline.py --config config.yaml --steps dge
```

## Experiment-specific notes

- **Strains:** NOD, B6G7, B6MHCIIGFP, NODPDL1
- **Conditions:** `CD45pos_MHCIIpos` (wells A1–A12), `CD45neg_MHCIIhi` (wells B1–E6),
  `CD45neg_MHCIIlo` (wells E7–H12)
- **Plate quirks:** B6MHCIIGFP wells H1–H12 are empty and absent from metadata;
  NODPDL1 plate layout is physically flipped but condition labels in metadata
  are biologically correct (flip already accounted for)
- **Batches:** B6G7 and B6MHCIIGFP = L001; NOD and NODPDL1 = L002
- **Normalization reference:** CD45pos_MHCIIpos (A1–A12) wells, per plate
- **DESeq2 design:** `~ condition` (no batch term; each strain is single-batch)
- **VST method:** `varianceStabilizingTransformation()` (direct call, bypasses
  sample size threshold check in the `vst()` wrapper)
- **Aligner:** HISAT2 (switched from STAR due to RAM constraints on Apple Silicon)
- **Annotation:** GENCODE vM33 primary assembly GTF
