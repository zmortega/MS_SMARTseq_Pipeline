# SMARTseq HT scRNA-seq Pipeline

Full-length, plate-based single-cell RNA-seq pipeline for differential expression,
dimensionality reduction, and cell type identification.
Optimized for **Takara SMARTseq mRNA HT** kits on **Apple Silicon Mac** with mouse (**GRCm39 / GENCODE vM33**).

---

## Pipeline overview

```
FASTQ (R1/R2 per cell)
    │
    ▼
[1] FastQC          → per-cell read quality reports
    │
    ▼
[2] Trimmomatic     → adapter trimming, quality filtering
    │
    ▼
[3] HISAT2          → splice-aware alignment to GRCm39
    │
    ▼
[4] featureCounts   → gene-level count matrix (all cells → one matrix)
    │
    ▼
[5] per_strain_plots.R
        ├── MHCII expression filter (H2-Aa & H2-Ab1, applied globally)
        ├── Per-strain DESeq2 (independent per plate, normalized to A1-A12)
        │       ├── Volcano plots (3 per strain)
        │       ├── Violin plots (3 per strain, top 20 DEGs each)
        │       ├── Expression matrix CSV (mean VST + upregulation rankings)
        │       └── Per-strain UMAP (by cluster + by population)
        └── Combined analysis (all MHCII-filtered cells)
                ├── Combined UMAP (by Leiden cluster + by strain/population)
                ├── Cluster composition bar charts
                ├── Cluster marker gene Excel (Wilcoxon rank-sum)
                ├── Cluster marker gene heatmap
                ├── Cluster violin plots (selected genes)
                └── Cell identity scoring Excel (CellMarker 2.0)
```

## Quick start

### 1. Install dependencies

```bash
conda env create -f environment.yml
conda activate smartseq_ht
```

### 2. Build the HISAT2 index (one-time)

```bash
hisat2-build -p 8 reference/GRCm39.primary_assembly.genome.fa reference/hisat2_index/genome
```

### 3. Prepare your metadata

Edit `data/metadata.csv` — one row per cell with columns:
`cell_id`, `strain`, `condition`, `batch`

See `data/metadata_example.csv` for format reference.

### 4. Configure

Edit `config.yaml`:
- Set `FASTQ_DIR` to your folder of `.fastq.gz` files
- Set `METADATA_FILE` to your metadata CSV

### 5. Run alignment and counting

```bash
python pipeline.py --config config.yaml
```

### 6. Run per-strain DGE, UMAPs, and all downstream analyses

```bash
cd ~/Desktop/MS_SMARTseq_Pipeline
Rscript scripts/per_strain_plots.R 2>&1 | tee per_strain_plots.log
```

> **Warning:** This script wipes and rebuilds `results/05_dge/` entirely on every run.
> Upstream folders (01–04, qc_summary) are never touched.

## File naming convention

The pipeline expects paired-end FASTQ files named:
```
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R1_001.fastq.gz
{STRAIN}_{WELL}_{SAMPLE}_{LANE}_R2_001.fastq.gz
```

Examples:
- `NOD_A1_S1_L002_R1_001.fastq.gz`
- `B6G7_H12_S96_L001_R1_001.fastq.gz`

Update `R1_SUFFIX` / `R2_SUFFIX` in `config.yaml` if your naming differs.

## per_strain_plots.R — detailed documentation

### MHCII expression filter

Applied globally before any DESeq2 or UMAP analysis. A cell is retained only
if both **H2-Aa** and **H2-Ab1** exceed a minimum expression threshold
(default: log1p(CPM) > log1p(5), roughly equivalent to VST > 1). Cells failing
this filter are removed from all downstream analyses including per-strain DESeq2,
expression matrices, UMAPs, clustering, bar charts, heatmap, marker genes, and
cell identity scoring.

The filter threshold and gene names are tunable at the top of the script:
```r
MHCII_VST_MIN <- 1.0
MHCII_GENES   <- c("H2-Aa", "H2-Ab1")
```

### Per-strain normalization

Each plate is treated as a fully independent experiment. Size factors are
estimated using only the **CD45pos_MHCIIpos (A1–A12) wells** of each plate as
the reference. The geometric mean expression profile is computed from those
reference cells (genes with any zero counts excluded), and median-of-ratios
scaling is applied to all cells on that plate. No cross-plate pooling occurs.

### Per-strain DESeq2

Design: `~ condition` (no batch term; each strain is single-batch).
VST: `varianceStabilizingTransformation()` (direct call, bypasses the sample
size threshold in the `vst()` wrapper).

### Per-strain contrasts

| Comparison | Volcano | Violins |
|---|---|---|
| CD45+ MHCIIpos vs CD45− MHCIIhi | 3 per strain | 3 per strain |
| CD45+ MHCIIpos vs CD45− MHCIIlo | | |
| CD45− MHCIIhi vs CD45− MHCIIlo  | | |

Each violin PDF contains 20 panels — top 10 up-regulated + top 10 down-regulated
DEGs by adjusted p-value — with gene symbols as labels and jittered VST points overlaid.

### Expression matrix columns

| Column | Description |
|---|---|
| `ensembl_id` | Ensembl gene ID |
| `gene_symbol` | Common gene name (GENCODE vM33) |
| `mean_VST_CD45pos_MHCIIpos` | Mean VST expression, CD45+ MHCIIpos cells |
| `mean_VST_CD45neg_MHCIIhi` | Mean VST expression, CD45− MHCIIhi cells |
| `mean_VST_CD45neg_MHCIIlo` | Mean VST expression, CD45− MHCIIlo cells |
| `rank_upregulated_MHCIIhi` | Upregulation rank vs CD45pos (1 = most upregulated) |
| `rank_upregulated_MHCIIlo` | Upregulation rank vs CD45pos (1 = most upregulated) |

Ranks use a combined score of `log2FC x -log10(padj)`. Genes not upregulated or
with missing statistics receive `NA`.

### Per-strain UMAPs

Two UMAPs per strain saved to each strain's output folder:
- **By Leiden cluster** — all-gene PCA used for clustering, top 2000 HVG UMAP for visualization
- **By population** — cells colored by CD45+/MHCIIhi/MHCIIlo condition

### Combined UMAP (all MHCII-filtered cells)

All four plates are combined after per-plate normalization. The VST matrices are
concatenated (genes common across all plates), then:

**UMAP embedding:** PCA on top 2000 highly variable genes → select PCs explaining
80% of variance → UMAP via `uwot`.

**Leiden clustering:** Separate PCA on all genes → select PCs at 80% variance
threshold → kNN graph → Leiden algorithm via `igraph`. This uses the full
transcriptome for clustering while the UMAP visualization is driven by HVGs.

**Tuning parameters** (all at top of script):
```r
N_HVG             <- 2000   # highly variable genes for UMAP
VAR_THRESHOLD     <- 0.80   # cumulative variance for PC selection
UMAP_N_NEIGHBORS  <- 15
UMAP_MIN_DIST     <- 0.3
LEIDEN_RESOLUTION <- 0.5    # higher = more clusters
UMAP_SEED         <- 42
```

### Cluster marker genes (Wilcoxon rank-sum)

For each cluster, a one-vs-rest Wilcoxon rank-sum test is run on the VST matrix.
Only genes with log2FC >= 0.5 are tested (pre-filter). Genes passing padj < 0.05
(BH correction) are ranked by log2FC and the top 100 are written to the Excel
workbook. The top 15 per cluster (deduplicated) are used for the heatmap.

Tunable parameters:
```r
MIN_LOG2FC  <- 0.5
MAX_PADJ    <- 0.05
TOP_EXCEL   <- 100
TOP_HEATMAP <- 15
```

### Cluster composition bar charts

Four stacked bar charts combined into a single 2x2 PDF:
- Counts by strain x population (12 colors)
- Proportions by strain x population
- Counts by strain (4 colors)
- Proportions by strain

Segment labels shown only for segments >= 5% of bar (`MIN_LABEL_PROP <- 0.05`).

### Cluster violin plots

Gene expression across Leiden clusters for selected genes. Add genes to the
`VIOLIN_GENES` vector at the top of the combined violin section:
```r
VIOLIN_GENES <- c("Ptprc", "H2-Aa", "Cd19")
```
Layout auto-adjusts to the number of genes (3 per row, PDF height scales).

### Cell identity scoring (CellMarker 2.0)

Marker genes per cluster are scored against CellMarker 2.0 mouse cell type
reference gene sets using Fisher's exact test (one-sided). The database is
downloaded fresh from CellMarker at runtime and cached to `/tmp/`. If the
download fails, a built-in curated fallback of 20 pancreatic/immune cell types
is used.

Scoring is performed for both the combined clusters and each per-strain cluster
set independently. Each Excel workbook contains a Summary sheet (top cell type
per cluster at a glance) and one sheet per cluster with the top 20 cell type
candidates including: rank, cell type name, overlap gene count, Jaccard
similarity, odds ratio, Fisher p-value, BH-adjusted p-value, and overlapping
gene symbols.

## Tuning reference (all parameters at top of script)

| Parameter | Default | Effect |
|---|---|---|
| `MHCII_VST_MIN` | 1.0 | Minimum VST for MHCII filter |
| `N_HVG` | 2000 | Highly variable genes for UMAP PCA |
| `VAR_THRESHOLD` | 0.80 | Cumulative variance for PC selection |
| `UMAP_N_NEIGHBORS` | 15 | UMAP local neighborhood size |
| `UMAP_MIN_DIST` | 0.3 | UMAP point spread |
| `LEIDEN_RESOLUTION` | 0.5 | Leiden cluster granularity |
| `UMAP_SEED` | 42 | Reproducibility seed |
| `MIN_LOG2FC` | 0.5 | Minimum log2FC for Wilcoxon pre-filter |
| `MAX_PADJ` | 0.05 | Adjusted p-value cutoff for markers |
| `TOP_EXCEL` | 100 | Marker genes per cluster in Excel |
| `TOP_HEATMAP` | 15 | Marker genes per cluster in heatmap |
| `MIN_LABEL_PROP` | 0.05 | Minimum bar segment size to show label |
| `VIOLIN_GENES` | c("Ptprc") | Genes for cluster violin plots |

## Advanced usage

### Resume a failed run
```bash
python pipeline.py --config config.yaml --resume
```

### Run only specific steps
```bash
python pipeline.py --config config.yaml --steps align,count,dge
```

### Run QC summary and flag low-quality cells
```bash
python qc_summary.py --config config.yaml
```
Then update `METADATA_FILE` in `config.yaml` to `results/qc_summary/metadata_qc_pass.csv` and rerun.

## Experiment-specific notes

- **Strains:** NOD, B6G7, B6MHCIIGFP, NODPDL1
- **Conditions:** `CD45pos_MHCIIpos` (wells A1–A12), `CD45neg_MHCIIhi` (wells B1–E6), `CD45neg_MHCIIlo` (wells E7–H12)
- **Plate quirks:** B6MHCIIGFP wells H1–H12 are empty and absent from metadata; NODPDL1 plate layout is physically flipped but condition labels in metadata are biologically correct (flip already accounted for during metadata construction)
- **Batches:** B6G7 and B6MHCIIGFP = L001; NOD and NODPDL1 = L002
- **Normalization reference:** CD45pos_MHCIIpos (A1–A12) wells, per plate
- **DESeq2 design:** `~ condition` (no batch term; each strain is single-batch)
- **VST method:** `varianceStabilizingTransformation()` (direct call, bypasses sample size threshold check in `vst()` wrapper)
- **Aligner:** HISAT2 (switched from STAR due to RAM constraints on Apple Silicon)
- **Annotation:** GENCODE vM33 primary assembly GTF
