# SMARTseq HT scRNA-seq Pipeline

Full-length, plate-based single-cell RNA-seq differential expression pipeline.
Optimized for **Takara SMARTseq mRNA HT** kits on **Apple Silicon Mac** with mouse (**GRCm39**).

---

## Pipeline overview

```
FASTQ (R1/R2 per cell)
    │
    ▼
[1] FastQC          → per-cell read quality reports
    │
    ▼
[2] Trimmomatic     → adapter trimming, quality filtering
    │
    ▼
[3] STAR            → splice-aware alignment to GRCm39
    │
    ▼
[4] featureCounts   → gene-level count matrix (all cells → one matrix)
    │
    ▼
[5] DESeq2          → differential gene expression, PCA, volcano, heatmap
```

## Quick start

### 1. Install conda (if not already)

```bash
# Download Miniforge (ARM-native conda for Apple Silicon)
curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-MacOSX-arm64.sh"
bash Miniforge3-MacOSX-arm64.sh
```

### 2. Create the environment

```bash
conda env create -f environment.yml
conda activate smartseq_ht
```

### 3. Download reference genome and build STAR index (~45 min, one-time)

```bash
bash setup.sh
```

### 4. Add your files

Place your FASTQ files in `data/fastq/`:
```
data/fastq/
├── PLATE1_A01_R1.fastq.gz
├── PLATE1_A01_R2.fastq.gz
├── PLATE1_B01_R1.fastq.gz
├── PLATE1_B01_R2.fastq.gz
└── ...
```

Create your metadata file at `data/metadata.csv`:
```csv
cell_id,condition
PLATE1_A01,control
PLATE1_A02,control
PLATE1_B01,treatment
PLATE1_B01,treatment
```
> The `cell_id` must exactly match the prefix before `_R1.fastq.gz`.
> See `data/metadata_example.csv` for a template.

### 5. Run the pipeline

```bash
python pipeline.py --config config.yaml
```

## File naming convention

The pipeline expects paired-end FASTQ files named:
```
{CELL_ID}_R1.fastq.gz
{CELL_ID}_R2.fastq.gz
```

Examples of valid cell IDs:
- `PLATE1_A01` → `PLATE1_A01_R1.fastq.gz` / `PLATE1_A01_R2.fastq.gz`
- `sample_001` → `sample_001_R1.fastq.gz` / `sample_001_R2.fastq.gz`
- `ctrl_rep1`  → `ctrl_rep1_R1.fastq.gz`  / `ctrl_rep1_R2.fastq.gz`

If your files use different suffixes (e.g. `_1.fastq.gz`), update `R1_SUFFIX` / `R2_SUFFIX` in `config.yaml`.

## Output structure

```
results/
├── 01_fastqc/                  per-cell FastQC HTML + zip
├── 01_fastqc_multiqc/          MultiQC summary of raw read QC
├── 02_trimmed/                 trimmed paired FASTQ per cell
├── 03_aligned/                 sorted BAM + index per cell
├── 03_aligned_multiqc/         MultiQC alignment statistics
├── 04_counts/
│   ├── raw_counts.txt          featureCounts raw output
│   └── counts_clean.txt        cleaned count matrix (cells as columns)
├── 05_dge/
│   ├── dge_all_genes.csv       full DESeq2 results table
│   ├── dge_significant.csv     significant DEGs only
│   ├── dge_results.xlsx        Excel workbook with both sheets
│   ├── pca_plot.pdf/png        PCA of cells (VST-normalized)
│   ├── volcano_plot.pdf/png    volcano plot
│   └── heatmap_top50_degs.pdf  expression heatmap, top 50 DEGs
└── qc_summary/                 (generated by qc_summary.py)
    ├── cell_qc_metrics.csv     per-cell QC stats + pass/fail flags
    ├── cell_qc_barplots.pdf    visual QC summary
    └── metadata_qc_pass.csv    metadata with failing cells removed
```

## Advanced usage

### Resume a failed run (skip completed steps)
```bash
python pipeline.py --config config.yaml --resume
```

### Run only specific steps
```bash
python pipeline.py --config config.yaml --steps align,count,dge
```

### Process a subset of cells
```bash
python pipeline.py --config config.yaml --cells PLATE1_A01,PLATE1_B01
```

### Run QC summary and flag low-quality cells
```bash
python qc_summary.py --config config.yaml
```
Then update `METADATA_FILE` in `config.yaml` to `results/qc_summary/metadata_qc_pass.csv` and re-run DGE:
```bash
python pipeline.py --config config.yaml --steps dge
```

### Batch correction (multiple plates/batches)
In `config.yaml`, change:
```yaml
DESIGN_FORMULA: "~ batch + condition"
```
Your `metadata.csv` must have a `batch` column.

## Notes on SMARTseq HT specifics

- **No UMIs**: SMARTseq HT is full-length with read counts (not UMI counts). featureCounts in paired-end mode (`-p`) is appropriate.
- **Strandedness**: SMARTseq libraries are typically **unstranded** (`-s 0` in featureCounts). If in doubt, run `infer_experiment.py` from RSeQC.
- **Cell = sample**: Each cell is a separate library. DESeq2 treats cells as replicates within conditions.
- **Adapter**: SMARTseq HT with Illumina sequencing uses standard **TruSeq3-PE** adapters.
